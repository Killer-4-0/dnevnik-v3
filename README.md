# Мой дневник здоровья (v3)

Дневник питания с КБЖУ, тренировками, планами, графиками и прогнозом веса. Работает офлайн (PWA), устанавливается на телефон. Данные хранятся на устройстве (localStorage), синхронизация между устройствами — опционально через Firebase.

Возможности: поиск по встроенной базе продуктов (~160 позиций) + Open Food Facts, штрихкоды, голосовой ввод, свои блюда и рецепты, план питания, тренировочные планы с записью подходов и таймером отдыха, графики веса и калорий, прогноз достижения цели, недельные итоги, экспорт/импорт данных.

## Открыть с телефона

### Через GitHub Pages (бесплатно)

1. Залейте файлы в репозиторий GitHub (например, `dnevnik-v3`):
   ```
   git init
   git add .
   git commit -m "v3"
   git remote add origin https://github.com/ВАШ_ЛОГИН/dnevnik-v3.git
   git push -u origin main
   ```
2. GitHub → репозиторий → **Settings** → **Pages** → Source: **Deploy from a branch** → ветка `main`, папка `/ (root)` → **Save**.
3. Через минуту приложение на `https://ВАШ_ЛОГИН.github.io/dnevnik-v3/`.
4. На телефоне: откройте ссылку → меню Chrome `⋮` → **«Установить приложение» / «Добавить на главный экран»** — работает как обычное приложение, в том числе офлайн.

### Через локальный сервер (домашняя Wi-Fi сеть)

```
node server.js
```
Компьютер: `http://localhost:8787`. Телефон (та же сеть): `http://IP-компьютера:8787` (IP смотри командой `ipconfig` — IPv4-адрес).

## Синхронизация между устройствами (опционально)

Настройки → «Синхронизация (вход по почте)» → пошаговая инструкция внутри. Нужен бесплатный проект Firebase (около 5 минут). Без настройки данные живут только на одном устройстве.

## Бэкап

Настройки → «Данные» → «Экспорт» — скачивается JSON со всеми записями. Храните копию: очистка данных браузера стирает дневник.

## Что не реализовано

- **Распознавание еды по фото** — вкладка в поиске еды показывает «Не реализовано». Добавляйте еду через поиск, голосовой ввод или вручную.
